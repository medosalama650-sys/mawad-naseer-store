# معوض نصير ستور

واجهة متجر جملة عربية RTL متوافقة مع الهاتف، مبنية كصفحة HTML واحدة.

## تشغيل الموقع مجانًا عبر GitHub Pages
1. افتح إعدادات المستودع: https://github.com/medosalama650-sys/mawad-naseer-store/settings/pages
2. من **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/ (root)** ثم اضغط **Save**.
4. انتظر حتى يظهر رابط النشر في نفس صفحة Pages.

## قبل الاستخدام الفعلي
- الأصناف والأسعار الموجودة أمثلة عامة، عدّلها إلى منتجات قانونية متاحة للبيع وأسعار مؤكدة.
- أدخل رقم واتساب المتجر الصحيح في النموذج عند تجهيز الطلب.
- هذه نسخة تجريبية: لا يوجد حساب مدير أو قاعدة بيانات سحابية؛ سلة الطلب مؤقتة على جهاز الزائر ولا تُحفظ الطلبات في لوحة إدارة.
