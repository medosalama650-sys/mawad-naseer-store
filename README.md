# كابتن الجيم | Gym Coach

تطبيق عربي باللهجة المصرية لمساعدة رواد الجيم على فهم التمارين والأجهزة، إنشاء نموذج جدول تدريب عام، تعلم أساسيات التغذية، وتسجيل التقدم.

## رابط المشروع
- المستودع: https://github.com/medosalama650-sys/mawad-naseer-store
- رابط GitHub Pages بعد دمج التحديث في `main`: https://medosalama650-sys.github.io/mawad-naseer-store/

## المميزات الحالية في النسخة الأولى
- واجهة عربية RTL بتصميم أسود وأخضر وذهبي ومتوافقة مع الموبايل.
- مكتبة تمارين مصنفة حسب العضلة مع شرح خطوات الأداء والتنبيهات الأساسية.
- نموذج جدول تدريب حسب المستوى وعدد الأيام والهدف ووقت التمرين.
- قسم تغذية عامة وأمثلة مرنة لأكل متوازن.
- مساعد إرشادي تجريبي بإجابات محلية باللهجة المصرية للأسئلة الشائعة.
- سجل تمرين للأوزان والمجموعات والتكرارات والتاريخ.
- حفظ السجل والجداول محليًا لكل حساب، مع تسجيل الدخول بالبريد وكلمة المرور.
- مزامنة سجل التمرين والجداول مع Firestore لكل مستخدم بعد نشر قواعد الأمان الجديدة.
- استعادة كلمة المرور وتسجيل الخروج، مع فصل بيانات كل حساب عن حسابات الجهاز الأخرى.
- إعداد PWA للتثبيت والعمل بموارد مخزنة مؤقتًا.

## مهم قبل الاستخدام
- النسخة الحالية نموذج أولي؛ بيانات السجل والجداول محفوظة على الجهاز الحالي فقط، وليست متزامنة بين الأجهزة أو الحسابات.
- المساعد الحالي لا يستخدم نموذج ذكاء اصطناعي متصلًا بالإنترنت؛ إجاباته مبنية على قواعد ومحتوى داخل التطبيق.
- لا توجد بعد لوحة إدارة محتوى للجيم أو محادثة ذكاء اصطناعي توليدية متصلة بخدمة خارجية.
- يجب نشر قواعد `firestore.rules` من Firebase Console حتى تعمل المزامنة السحابية؛ رفع الملف إلى GitHub وحده لا ينشر القواعد.
- لا تستخدم التطبيق لتشخيص الإصابات أو وصف علاج أو حمية علاجية. يجب مراجعة مدرب مؤهل لضبط الأجهزة، ومختص صحي عند وجود إصابة أو حالة صحية.
- لا تختبر أقصى أوزانك وحدك، وتوقف عند الألم أو الدوخة.

## الحفاظ على بيانات المتجر القديمة
تم تنفيذ التحويل على فرع مستقل باسم `gym-coach-v1` بدل استبدال `main` مباشرة. ملفات بيانات Firebase القديمة ومجموعات `products` و`orders` وقواعد Firestore لم يتم تعديلها. ملف `admin.html` ما زال لوحة المتجر القديمة، وليس لوحة إدارة الجيم.

## النشر
بعد مراجعة التغييرات ودمج الفرع في `main)، تأكد من إعداد GitHub Pages على:
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/(root)`

ثم افتح رابط الموقع واعمل تحديثًا كاملًا، أو أزل النسخة المثبتة القديمة وثبّت التطبيق من جديد لتحديث الاسم والأيقونة وملفات PWA.
